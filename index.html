Russian non-working days

Public holidays, weekends, moved days off and shortened workdays in Russia, as a calendar you subscribe to once. It updates itself every week.

Any other app: paste the link wherever it offers “Subscribe” or “Add calendar from URL”. A subscription keeps itself up to date; a downloaded file does not.

    How to add

    iPhone, iPad, Mac

    Tap “Apple Calendar” above and confirm “Subscribe”. By hand on iPhone: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar, then paste the link (on iOS 18 and later Calendar is under Settings → Apps). On Mac: Calendar → File → New Calendar Subscription.

    Google Calendar

    On a computer, open “Google Calendar” above and confirm. By hand: calendar.google.com → Other calendars → + → From URL, paste the link. The phone app cannot add a calendar by link, but it shows the calendar once it is added on the web.

    Android

    Add the calendar to Google Calendar on a computer (see above). It then syncs to the Google Calendar app; if it does not show up, open the app's settings, find the calendar and turn on sync.

    Outlook

    “Outlook” above works for personal Outlook.com accounts. For a work or school account, open Outlook on the web → Calendar → Add calendar → Subscribe from web and paste the link.
